# Weddingle — digital wedding invitations

Published with GitHub Pages: https://invitashion.online/

- `goa-beach/` — Goa sunset beach invitation (demo couple: Isha & Aarav, 1 Nov 2026)

Each invitation is a single self-contained page. Music (a song file, or music generated in
the browser with the Web Audio API) starts when the guest taps "Open Invitation".
